Selection Process

The selection process includes initial application screening, a Written Test or Computer Based Test (CBT), and a qualifying Skill Test. For driver posts, the Skill Test is a practical driving assessment.

  1. Initial Screening: Applications will be screened using academic performance and other prescribed parameters.
  2. Written Examination / CBT: Screened-in candidates will appear for the applicable objective examination.
  3. Skill Test: Candidates shortlisted based on written examination performance will be called for a qualifying skill or driving test.
  4. Document Verification: Original educational, experience, reservation and other eligibility documents will be verified.
  5. Final Selection: Selection will follow the prescribed written examination merit and qualifying skill test requirements.
